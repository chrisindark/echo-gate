# Echo Gate UI — project guide

The block above is generated by `next dev`; keep it. This section is the
project-specific guide the block does not cover.

## What this app is

The observability and playground frontend for the Echo Gate gateway (the FastAPI
service in the repo root — see `../AGENTS.md` and `../docs/`). It is a separate
**Next.js 16** App Router app (React 19, Tailwind CSS v4, Radix UI Themes,
`framer-motion`, `lucide-react`). It is not part of the Python package and has its
own `package.json`.

## Commands

```bash
npm install      # install dependencies
npm run dev      # dev server on http://localhost:3000
npm run build    # production build (run before claiming a UI change works)
npm run start    # serve the production build
npm run lint     # eslint
```

Run `npm run lint` and `npm run build` before declaring a UI change done. The
gateway must be running for the UI to show real data:

```bash
# from the repo root
poetry run uvicorn app.main:app --port 8000 --reload
# or start backend + UI together
./dev.sh
```

## Layout

- `src/app/layout.tsx` — root layout and providers.
- `src/app/page.tsx` — chat playground. Provider/model pickers, temperature, max
  tokens, structured-output modes (`text` / `json_object` / `json_schema`), API key +
  tenant/user headers, cache-status badges. Supports `?hash=<exact_hash>` to reload a
  stored trace.
- `src/app/traces/page.tsx` — gateway request trace table.
- `src/app/traces/[id]/page.tsx` — trace detail (latency waterfall, intent metadata,
  evaluation scores).
- `src/app/analytics/page.tsx` — dashboard KPIs, cache performance, model breakdown,
  latency metrics.
- `src/components/app-sidebar.tsx` — navigation.

## Rules and caveats

- **API base URL is hardcoded** to `http://localhost:8000` (in `src/app/page.tsx`
  and the trace pages); there is no environment variable yet. A hosted deployment
  needs this made configurable.
- **Keep the model allowlist in sync.** `src/app/page.tsx` has a `PROVIDERS` map that
  mirrors the gateway's per-provider allowlist in
  `../app/modules/chat/chat_schema.py` (`ALLOWED_MODELS`). When the backend adds or
  removes a model, update both.
- **The sidebar links `/cache` and `/settings` have no routes** — clicking them 404s.
  This is a known gap; do not "fix" it silently.
- No charting library is installed; the analytics page renders cards and tables.
- Follow the existing component/formatting style. Do not reformat unrelated files.
