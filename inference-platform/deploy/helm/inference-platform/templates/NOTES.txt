Point consumers at it:

  INFERENCE_BASE_URL=http://{{ include "inference-platform.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}

Run the drift guard from a checkout of the repo against this deployment:

  INFERENCE_BASE_URL=http://localhost:{{ .Values.service.port }} uv run python evals/check.py

Notes:
- The container has no authentication. Keep this Service cluster-internal
  (ClusterIP) and put authorization in front of the consumers, not here.
- Liveness is a TCP check on purpose: a permanently unloaded role must be visible
  as "unready" and stay inspectable rather than restart-looping.
- Scaling on CPU is a compromise; the work is model-bound. On a GPU pool, scale
  on queue depth instead, and keep a warm weight volume.
