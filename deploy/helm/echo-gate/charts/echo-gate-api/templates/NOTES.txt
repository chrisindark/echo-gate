Secret mounting: set echo-gate-api.existingSecret (or extraEnvFromSecrets) to
mount a pre-created Secret (e.g. from cert-manager / External Secrets). Provider
keys (OPENAI_API_KEY, etc.) and DATABASE_URL / MIGRATION_DATABASE_URL come from
that Secret — never from values.yaml in plain text.

TLS: echo-gate-api.ingress.enabled=true provisions an Ingress; point its tls
secretName at a cert-manager Certificate (or pre-signed Secret). The gateway
itself serves HTTP inside the cluster; TLS terminates at the Ingress.
